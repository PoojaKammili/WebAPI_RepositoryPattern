WebAPI_RepositoryPattern
📘 Description

This is an ASP.NET Core Web API project demonstrating the Repository Pattern.
The project separates data access logic from business logic using repositories, making the application easier to maintain and test.

The API performs CRUD operations on an entity (Employee / Student / Product) using a clean layered architecture.

🚀 Features

Implements Repository Pattern

Performs Create, Read, Update, Delete (CRUD) operations

Clear separation of concerns

Uses Service layer + Repository layer

Clean project structure following best practices

🧱 Tech Stack

Language: C#

Framework: ASP.NET Core Web API (.NET 6 / .NET 7 / .NET 8)

Pattern: Repository Pattern

ORM: Entity Framework Core

Database: SQL Server / In-Memory

IDE: Visual Studio / VS Code
